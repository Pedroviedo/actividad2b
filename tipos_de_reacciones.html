Tipos de reacciones

🔗 1. Reacción de síntesis (unión)
👉 Dos sustancias se unen para formar una sola

Forma general:
A + B → AB

Ejemplo:
Hierro + oxígeno → óxido de hierro (herrumbre)


💥 2. Reacción de descomposición
👉 Una sustancia se rompe en varias

Forma general:
AB → A + B

Ejemplo:
Agua → hidrógeno + oxígeno (con electricidad)


🔄 3. Reacción de sustitución (desplazamiento)
👉 Un elemento reemplaza a otro

Forma general:
A + BC → AC + B

Ejemplo:
Zinc + ácido → hidrógeno + sal


🔁 4. Doble sustitución
👉 Dos compuestos intercambian partes

Forma general:
AB + CD → AD + CB

Ejemplo:
Sal + otro compuesto → se forma un sólido (precipitado)


🔥 5. Combustión
👉 Una sustancia reacciona con oxígeno y libera energía

Ejemplo:
Madera + oxígeno → dióxido de carbono + agua + energía 🔥


🧠 Resumen fácil
Síntesis → se juntan
Descomposición → se separan
Sustitución → uno reemplaza a otro
Doble sustitución → intercambian
Combustión → reacción con oxígeno y energía
