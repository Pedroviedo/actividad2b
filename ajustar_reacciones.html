Ajustar reacciones

Ajustar (o balancear) una reacción significa:

➡️ Poner los números correctos para que haya el mismo número de átomos en ambos lados.

👉 Porque en una reacción química:
los átomos no se crean ni se destruyen, solo se reorganizan


🧠 Idea clave
Si tienes esto:

H₂ + O₂ → H₂O

❌ No está ajustada (no hay los mismos átomos)

✔️ Ajustada sería:
2H₂ + O₂ → 2H₂O


🔢 ¿Cómo se ajusta paso a paso?
🧪 Paso 1: Cuenta los átomos
Ejemplo:

H₂ + O₂ → H₂O

Izquierda: H = 2, O = 2
Derecha: H = 2, O = 1 ❌

🧪 Paso 2: Ajusta poniendo números delante
👉 Nunca cambies las letras (eso sería otra sustancia)

Pon números delante:

2H₂ + O₂ → 2H₂O


🧪 Paso 3: Comprueba
Izquierda: H = 4, O = 2
Derecha: H = 4, O = 2 ✔️
👉 Ya está ajustada


🧪 Otro ejemplo fácil
Fe + O₂ → Fe₂O₃

👉 Paso a paso:

Ajusta el hierro (Fe):
2Fe + O₂ → Fe₂O₃
Ajusta el oxígeno (O):
2Fe + 3/2 O₂ → Fe₂O₃
Quita fracciones (multiplica todo por 2):
4Fe + 3O₂ → 2Fe₂O₃ ✔️

⚠️ Reglas importantes
✅ Solo puedes poner números delante (coeficientes)
❌ No puedes cambiar las fórmulas
✅ Debe haber el mismo número de átomos a ambos lados
